클러스터 추가

수집은 backend 안의 chDB가 remote()/remoteSecure()로 직접 접속합니다. 브라우저는 backend API만 호출합니다.

수집 경로는 ClickHouse native TCP protocol을 사용합니다. HTTP 인터페이스 포트(보통 8123/8443)는 사용할 수 없습니다. 포트 번호만으로 판단하지 않고, 연결 테스트에서 서버 응답으로 확인합니다.

remoteSecure() 사용 · 인증서는 strict 검증 (평문은 격리된 로컬 테스트에서만 권장)

필요 권한: system.metrics, system.query_log SELECT (필수) · system.clusters SELECT (노드 범위 확인용, 선택). 비밀번호는 backend의 암호화된 chDB named collection에만 저장되며 다시 표시되지 않습니다.
